## 🚀 Despliegue Inmediato

### Opción 1: Netlify Drop (Recomendada — 10 segundos sin comandos)
1. Entra a [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Inicia sesión con tu cuenta.
3. Arrastra esta carpeta completa (`bruma-savia-deploy`) al navegador.
4. ¡Listo! Netlify te entrega un dominio público activo al instante.

### Opción 2: Vercel
1. Ejecuta `vercel` en la terminal dentro de esta carpeta, o
2. Sube la carpeta a GitHub y conéctala en [vercel.com](https://vercel.com).
